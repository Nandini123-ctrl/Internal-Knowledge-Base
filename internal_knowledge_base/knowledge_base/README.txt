Internal Knowledge Base Project
===================================

This is a complete, ready-made Internal Knowledge Base prototype using Python (Flask), SQLite, and HTML.

Setup Instructions:
-------------------
1. Make sure you have Python installed on your computer.
2. Open your terminal or command prompt.
3. Install Flask by running:
   pip install Flask
4. Run the application:
   python app.py
5. Open your web browser and go to:
   http://127.0.0.1:5000
